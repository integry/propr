# Official plugins

ProPR ships 10 official plugins. Each one is a folder
`packages/plugins/<id>/` in the ProPR repository, reviewed and released with
ProPR itself: installing one downloads nothing (except the pinned npm package
of a local MCP server). An administrator installs, configures and enables them
on the **Plugins** page; see [Plugins](../features/plugins.md) for how that
works and [Writing a plugin](./authoring.md) to add one.

## By category

### Messaging

- [Slack](./slack.md): Posts short ProPR notifications (pull requests opened, merged or closed, review scores, Ultrafix outcomes, failed tasks, epic queues blocked or completed) to Slack, through incoming webhooks or, with your own Slack app, in one thread per pull request.
- [Discord](./discord.md): Posts short ProPR notifications (pull requests opened, merged or closed, review scores, Ultrafix outcomes, failed tasks, epic queues blocked or completed) to Discord channels as embeds through channel webhooks.
- [Microsoft Teams](./teams.md): Posts short ProPR notifications (pull requests opened, merged or closed, review scores, Ultrafix outcomes, failed tasks, epic queues blocked or completed) to Microsoft Teams channels or chats as Adaptive Cards through a Workflows webhook.

### Issue tracking

- [Linear](./linear.md): Hands Linear tickets to ProPR and keeps them in sync.
- [Jira Cloud](./jira.md): Hands Jira Cloud tickets to ProPR and keeps them in sync.

### Observability

- [Sentry](./sentry.md): Turns Sentry errors into GitHub issues for ProPR.

### Deployment

- [Cloudflare](./cloudflare.md): Deploy a pull request to Cloudflare from a comment: /deploy (or /deploy-cloudflare) has the agent deploy the branch as a Cloudflare Pages or Workers preview through Cloudflare's API MCP server and reply with the URL.
- [Vercel](./vercel.md): Deploy a pull request to Vercel from a comment: /deploy (or /deploy-vercel) has the agent create a Vercel preview deployment of the branch through Vercel's MCP server and reply with the URL.

### Context

- [Notion](./notion.md): Lets the agent read the Notion pages an issue or pull request links to, such as specifications, through Notion's hosted MCP server.

### Other

- [Outbound webhooks](./webhooks.md): Sends ProPR events (pull requests opened, reviews scored, Ultrafix runs ended, pull requests merged or closed, task progress, epic queue blocked or completed) as signed JSON to any HTTPS endpoint.
