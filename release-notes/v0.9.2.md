## Highlights

ProPR 0.9.2 makes it easier to see which pull requests need you, adds ready-made automations, and brings new models. Full details: [What's new in 0.9.2](https://propr.dev/whats-new/0.9.2/) and the [changelog](https://github.com/integry/propr/blob/v0.9.2/CHANGELOG.md).

**Pull requests**
- **One status per pull request.** Every pull request ProPR opens is `working`, `needs attention` or `ready`, with the reason: the Ultrafix cycle, the latest review score, checks, conflicts and epic progress. It is in the PR list, the API, MCP and, if you turn it on, in the PR title.
- **Epic progress** in the epic PR's title, status line and progress comment.
- **Clearer bot comments.** One CI-failure comment per commit, a review digest and an acceptance-criteria checklist in the PR description, and a run summary that is an actual summary.

**Automations**
- **Templates** to start from, including a weekly drift report and an instruction learning loop.
- **Run when an epic issue gets blocked**, and a **Repeat** schedule you set without writing cron.
- Acting steps can review, approve CI, label, close and merge; runs that change nothing are flagged; the list has search and a repository filter.

**Agents and models**
- **Claude Fable 5.2**, **GPT-6.2 Astra** (the new `astra` default) and **GPT-6.2 Sol**, **GPT-6.1 Terra** and **Gemini 4 Hydrogen**.
- Bundled CLIs: Claude Code 2.1.326, Codex 0.169.0, Antigravity CLI 1.5.10, OpenCode 1.19.6 and Mistral Vibe 2.25.8.
- Claude goals can ask you a question, and agents can stop and report a blocker instead of guessing.

**Extensions**
- **One extension library** replaces extension profiles: MCP servers and skills, each limited to the repositories and agents you choose, applied automatically to matching runs. The `disable-mcps`, `disable-skills` and `disable-extensions` labels switch them off for one issue or pull request.
- **Local MCP servers from npm packages**, pinned to an exact version and integrity hash, and OAuth sign-in for HTTPS MCP servers.

**Cost and control**
- **LLM cost export** by day, repository, agent, model and outcome (JSON and CSV), spend on failed attempts, and token-outlier alerts.
- Per-agent ceilings make jobs wait in the queue instead of failing.

**Fixes and security**
- Many fixes from a release-wide check of the API, MCP tools, CLI, worker and web UI, including JSON errors everywhere in the API, repository filters limited to configured repositories, Ultrafix loops that no longer end as failed, and many phone-width and consistency fixes in the web UI.
- Dependency advisories fixed for `picomatch` (GHSA-fc5q-39xc-vjpf) and `hono`.

## Upgrade notes

- **Extension profiles:** each server and skill from a profile becomes a library item with the same limits and with **Apply automatically** off, and automations keep their items. No run changes until you turn an item on.
- **API paging:** `GET /api/goals` without `limit` now returns one page of 50 (follow `nextOffset`), and `GET /api/tasks` accepts at most `limit=200`.
- **Claude Sonnet 4.5** is retired by Anthropic on 2026-11-30; from then, saved Sonnet 4.5 selections run Claude Sonnet 5.5.
- The database is migrated on first start. Starting an older image on the migrated database is refused, so back up before upgrading if you may need to roll back.
